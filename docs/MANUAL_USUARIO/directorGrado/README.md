# Manual de usuario -- Director de Grado

pyCelda gestiona el catálogo académico del grado (materias, asignaturas, resultados de aprendizaje) y el ciclo de revisión de las guías docentes de sus asignaturas.

## Qué permite hacer

- Consultar los grados a cargo y el estado de sus guías docentes.
- Gestionar las materias del grado: asociar y desasociar metodologías docentes y resultados de aprendizaje, editar el reparto de sus actividades formativas.
- Editar las asignaturas de grado: datos propios y requisitos previos, asociaciones de metodologías docentes y resultados de aprendizaje, reparto de actividades formativas.
- Gestionar el catálogo de resultados de aprendizaje del grado: crear, editar y eliminar.
- Revisar las guías docentes del grado: aprobar, rechazar, escalar directamente a aprobada, revocar una aprobación, editar el semestre y notificar guías actualizadas a Admin.

Si la cuenta también imparte alguna asignatura, la gestión de esa guía propia (redactar el temario, la evaluación, la bibliografía y la planificación docente) se explica en el [manual de Profesor](../profesor/README.md), no en este.

Para el mapa completo de qué depende de qué y quién gestiona cada bloque del sistema, ver [Cómo se organiza pyCelda en conjunto](../estructuraDelSistema.md).
