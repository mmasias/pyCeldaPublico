# Manual de usuario -- Admin

pyCelda gestiona el catálogo académico de la institución (universidades, facultades, grados, asignaturas, materias, sistemas de evaluación), el profesorado y el seguimiento del estado de las guías docentes.

## Qué permite hacer

- Consultar universidades y facultades, y gestionar los grados que cuelgan de cada facultad: crear, editar el nombre, dar de baja.
- Gestionar el catálogo institucional de asignaturas y el de metodologías docentes: crear, editar, dar de baja.
- Gestionar las materias de un grado y sus sistemas de evaluación: crear materias, y crear, editar o eliminar sistemas de evaluación.
- Gestionar las asignaturas de un grado: crear, editar, dar de baja, y asignar o desasignar profesorado.
- Gestionar el profesorado: crear, editar, dar de baja, y nombrar o quitar director de grado.
- Consultar el estado de las guías docentes de un grado, previsualizarlas y descargar su PDF.
- Consultar el listado de copias de seguridad de la base de datos.

Cursos académicos y la generación masiva de guías en PDF no están disponibles en esta versión.

Para el mapa completo de qué depende de qué y quién gestiona cada bloque del sistema, ver [Cómo se organiza pyCelda en conjunto](../estructuraDelSistema.md).
