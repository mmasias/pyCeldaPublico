# Copias de seguridad

## Qué es

El listado de las copias de seguridad de la base de datos, para comprobar que se están generando con normalidad. Es de solo consulta: las copias se generan automáticamente, no hay ninguna acción que realizar desde aquí.

## Cómo llegar

Pulsar **Copias de seguridad** en el panel de administración.

## Qué muestra

Una tabla con **Familia** (**Diario** o **Puntual**), **Fecha**, **Tamaño** y **Motivo** de cada copia. Si todavía no hay ninguna registrada, la pantalla lo indica.
